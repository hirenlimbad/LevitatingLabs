# 🧬 LevitatingLabs

> **An open-source research notebook dedicated to AI in drug discovery, GNN architectures, ESM-2 protein language models, and zero-shot OOD benchmarks.**

Levitating Labs is an open research notebook exploring machine learning, graph neural networks (GNNs), and pre-trained protein language models (ESM-2) for biomedical discovery. Bypassing traditional journal submission latency, we share empirical benchmarks, zero-shot OOD evaluations, and transparent computational codebases in real time.

---

## ⚡ Tech Stack & Features

- **Framework**: Astro 5 (Static Site Generation)
- **Styling**: Tailwind CSS v4 (Electric Indigo & Slate Palette)
- **Typography & Math**: KaTeX math rendering, Shiki code syntax highlighting
- **Search & Navigation**: Pagefind static search, collapsible Table of Contents, Figures & Artifacts navigation
- **Deployment**: GitHub Pages workflow (`.github/workflows/deploy.yml`)

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
